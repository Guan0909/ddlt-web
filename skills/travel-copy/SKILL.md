# 点定旅途 · 旅行文案文体规范（travel-copy）

## 红线（不可违反）

1. 只解释已经存在的行程事实：站点、天数、线路名、起终点、通勤方式、站点自带的时段标签（早去/夜景等）、是否远郊日。
2. 禁止生成：新地点、坐标、营业/闭馆时间、价格、天气、交通班次、客流预测。
3. 禁止表情符号、感叹号连用、"绝绝子/YYDS/必打卡"类网络腔、夸张最高级（最、第一、必去）。
4. 输出长度：总推荐语目标 **60~90 字**，硬上限 **110 字**（超出由云函数截断补省略号）；单行理由 ≤24 字。

## 文体特征（编辑感 / editorial）

- **克制陈述**：用名词和动词，少用形容词；把判断藏在顺序和选择里（"博物馆排在午后最热时"）。
- **具体时间锚点**：用行程里已有的时刻与标签说话（"赶早""灯亮之后""午后最热时"），不造新时间。
- **短句收束**：两句以内说完；句读干净，多用逗号、破折号，不用排比。
- **城乡节奏**：多日行程的叙事要有"城里慢、城外赶"或"白天馆、入夜灯"的节奏对比。

## Few-shot 样例（照此语感，不照抄）

输入：成都 3 日，D1 城内古迹线（成博/人民公园/宽窄/武侯祠/草堂），D2 东北亲子线（熊猫基地（早去）/川博/东郊），D3 远郊山水线（钟书阁/熊猫谷/都江堰），起点天府广场。
输出：城里两天慢慢逛：博物馆排在午后，茶社留给上午；第三天赶早去都江堰。三国、诗圣和熊猫，一个都没绕路。

输入：杭州 3 日，D1 西湖环线，D2 茶山线（龙井/九溪），D3 远郊（湿地），起点湖滨。
输出：第一天沿湖慢走，把落日留给长桥；第二天进山里问茶，寺、溪、田都在一条线上；第三天赶早去湿地。湖与山，各占了合适的时辰。

输入：北京 1 日，中轴线（故宫/景山/什刹海），起点王府井。
输出：一天只安排中轴：故宫一上午，景山看全景，什刹海收尾吃晚饭。

## 使用方式

- `aiCopy` 云函数叙事（`cloudfunctions/aiCopy/index.js`）：system prompt 内嵌本规范要点 + 样例一/二；输入 digest 为引擎事实（日标签、站点名与顺序、时段标签、是否远郊日）。
- 降级策略：5s 超时或异常 → 返回 `fallback:true`，前端整行隐藏叙事，**不显示模板文案**。
- 人工润色离线文案（spots 的 reason/intro）：遵守同一文体与红线。
