# 点定旅途 · 旅行文案文体规范（travel-copy）

## 红线（不可违反）

1. 只解释已经存在的行程事实：站点、天数、线路名、起终点、通勤方式。
2. 禁止生成：新地点、坐标、营业/闭馆时间、价格、天气、交通班次、客流预测。
3. 禁止表情符号、感叹号连用、"绝绝子/YYDS/必打卡"类网络腔、夸张最高级（最、第一、必去）。
4. 输出长度：总推荐语 60~90 字；单行理由 ≤24 字。

## 文体特征（编辑感 / editorial）

- **克制陈述**：用名词和动词，少用形容词；把判断藏在顺序和选择里（"博物馆排在午后最热时"）。
- **具体时间锚点**：用行程里已有的时刻说话（"赶早""灯亮之后""午后最热时"），不造新时间。
- **短句收束**：两句以内说完；句读干净，多用逗号、破折号，不用排比。
- **城乡节奏**：多日行程的叙事要有"城里慢、城外赶"或"白天馆、入夜灯"的节奏感。

## Few-shot 样例（照此语感，不照抄）

输入：成都 3 日，D1 城内古迹线（成博/人民公园/宽窄/武侯祠/草堂），D2 东北亲子线（熊猫基地/川博/东郊），D3 远郊山水线（钟书阁/熊猫谷/都江堰），起点天府广场。
输出：城里两天慢慢逛：博物馆排在午后，茶社留给上午；第三天赶早去都江堰。三国、诗圣和熊猫，一个都没绕路。

输入：杭州 2 日，D1 西湖环线（苏堤/孤山/灵隐），D2 茶山线（龙井/九溪），起点湖滨。
输出：第一天沿湖走，灵隐放在早晨人最少时；第二天进茶山，九溪十八涧走到哪算哪。

输入：北京 1 日，中轴线（故宫/景山/什刹海），起点王府井。
输出：一天只安排中轴：故宫一上午，景山看全景，什刹海收尾吃晚饭。

## 使用方式

- `aiCopy` 云函数叙事：system prompt 引用本规范 + 对应 few-shot。
- 人工润色离线文案（spots 的 reason/intro）：遵守同一文体与红线。
