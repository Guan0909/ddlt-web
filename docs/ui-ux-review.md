# 点定旅途 · UI/UX 审查与优化方案（2026-10-18）

> 方法：无头浏览器实测全流程（首页 → 建议 → 加载 → 结果 → 编辑旅途 → 分享 → 海报）+ 代码走查（index / loading / result / share / poster / app.js）。
> 截图证据：`build/a1-home.png`、`build/a2-city-drawer.png`、`build/b1-suggest.png`、`build/c1-result.png`、`build/c3-edit.png`、`build/c4-edit-search.png`、`build/c5-share.png`、`build/ui-poster-alevel.png`、`build/ui-result-alevel.png`

## 一、总体判断

视觉系统（纸白/绿/墨、衬线大标题、发丝线）统一且高级，Hero、统计行、Day 标签、海报都达到「可发布」水准。
问题集中在**信息密度与操作语义**：结果页把「浏览」和「编辑」两套界面揉在了一张卡片里；编辑态丢失了「当前在改哪一天」的上下文；搜索建议噪声大。以下按屏幕列问题、按优先级给方案。

## 二、逐屏问题清单

## 三、优化方案（按优先级）

### P0 · 主流程与信任（建议先做，约 2–3 天）
1. **结果页「浏览态 / 编辑态」分离**
   - 浏览态卡片只保留：名称 + A 级徽章、类目标签、缩略图、事实行（评分/营业/电话）、一句 reason；
   - 「时长档 + 上移/下移/换一站/移到另天/删除」收进「编辑旅程」开关（进入编辑后才展开），或卡片右下角「⋯」展开；
   - 收益：一屏可见 2–2.5 张卡，行程可读性大幅提升。
2. **编辑模式补「当前编辑天」上下文**
   - 顶部地图区加 Day 胶囊（D1/D2/D3 可点切换），并在底部显示「D2 · 已选 3 站 · 预计游览 4.5h · 通勤 0.8h」；
   - 「取消」改为「完成」/「返回」二选一，去掉语义重复。
3. **修缩略图破图**：`img.onerror` 时隐藏图片并回退为 A 级/类目色块占位；加 `loading=lazy` 已有，补 `decoding=async`。
4. **搜索建议治理**
   - 过滤类型：地铁站/公交站/停车场/购物中心/超市/便利店/公司等；
   - 同城优先、外地同名降权并标注「外地」；已开通城市优先；
   - 列表项加类型图标（景点/酒店/交通/商场），选中态更明确；
   - 加 150ms 骨架/「正在搜索…」占位，避免空白。

### P1 · 顺滑与信息利用（约 2 天）
5. **首页**：裸文本也允许生成（按钮 enabled，文案「回车即可，我们帮你解析」）；城市抽屉加搜索框 + 「最近去过/热门城市」两行；页脚精确显示 60 城并可点开城市列表；加「看一个示例路线」。
6. **结果页卡片点开轻详情抽屉**：多图（≤3 张，已采集 100%）、完整地址、营业时间原文、A 级标签、电话、评分，「去这里」唤起高德导航。
7. **编辑模式地图降噪**：标签碰撞避让（或只在放大后显示名称）+ 底部提示条与水印错位修正。
8. **加载页**：显示已耗时与阶段文案（「正在写入时刻表…」），>12s 出现安抚提示；失败态给「重试 / 换起点 / 返回首页」。
9. **分享页**：加静态路线缩略图（复用海报底图能力）+ 「我也要生成」主按钮上移。
10. **去掉「AI 文案」标签**（改「智能排线」或直接删除），避免信任折损。

### P2 · 打磨（约 1 天）
11. 结果页 Day tabs 吸顶 + 滚动联动地图（滚动到某天时自动切图）。
12. 通勤占比提示（>40% 时给出「减少远郊点/换交通方式」建议，纯前端文案）。
13. 触控目标 ≥44px；toast 支持一个主操作（"撤销"）。
14. 海报底部加短链域名（decidenow.asia）增强品牌记忆。
15. 骨架屏统一（首页建议、结果卡片、分享页）。

## 四、验收口径

- 结果页：3 天行程在 430×932 视口下，浏览态「不展开任何操作」可一屏看到 ≥2 张完整卡片；
- 编辑模式：进入后 1 秒内能看到「正在编辑 D2」；
- 搜索：输入「天府广场」前 3 条均为地理地标且同城优先；
- 图片：任一卡片图片加载失败时显示占位色块而非破图/alt 文本；
- 分享/海报：A 级徽章、评分、路线统计完整，无遮挡。
